# Bobbin 2.3.0

Node.js 20.20.0+ runs the packaged core and `.mjs` entrypoints. Python is not required.

Keep the thread. One plugin for durable project context.

Run `$bobbin:init` to select features and `explicit|auto|adaptive` recording for a project. Settings live in `.bobbin/config.json`. Existing records remain Markdown; disabling features never removes history. See [recording policy](skills/context/references/recording-policy.md) for approval, integrity and shared-vault behavior.
