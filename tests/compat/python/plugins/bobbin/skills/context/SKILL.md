# Context

Follow the [shared recording policy](references/recording-policy.md). Resolve project settings on a durable signal. Below, user approval means `explicit` mode; `auto|adaptive` use policy authorization without weakening semantic validity.

Vault: configured project vault, otherwise nearest `context/` ancestor or cwd; `--vault DIR` overrides for explicit operations. Apart from the shared recording policy, do not read `references/`, manifests, `context/*.index.md`, or plugin scripts. DEC recall uses the loaded `decision` skill: one `decision_cli.py check --statement '<request>' --json`. Other kinds use their loaded skill. No `--help`; inspect implementation source only after an unexplained interface failure.

Audit turn delta once. No durable signal means zero context tool calls or visible audit/capture question. A mechanical local edit that changes no behavior or contract skips AGENTS/guidance discovery and excludes `context/`. Named path: inspect only it. Otherwise infer one task subtree, list its files and search once, then use the exact file. Match filenames and contents. On a miss inspect listed candidates; if the subtree is absent, create the conventional file there. Never use `.`, `--hidden`, repo-wide globs or root; ask for the path instead of widening. Keep `context/` reads and context mentions at zero. Session-only ledger: scope/anchor, Current `{id,sha256}` whose actual bodies remain in context, and pending/dismissed/deferred refs; never persisted.

Use active language for user text, English for machine fields; preserve artifact meaning.

1. Recall when prior context changes judgment. A user choice is the signal; executing a request is not. Escalate: silent index check; selected body reads on a match; user mention only if action changes; question only if required.
2. Let the semantic owner compare actual claims, sections, scope, and rationale. Hashes, IDs, and metadata are not semantic evidence. Report conflict or rationale change before the conclusion and hold the affected action: keep means not performed; supersede permits it only after that explicit choice. A satisfied revisit condition permits reassessment, not implementation. That choice settles the decision payload; no separate storage approval.
3. Finish the request first; propose mature context once per milestone.
4. Core alone writes after validating owners, lifecycle, indexes, target bytes, vault identity, CAS, lock, and frozen bundle.

Follow the shared recording policy for user or policy authorization. DEC uses one `record`; internal preview and unchanged apply keep transport private.
